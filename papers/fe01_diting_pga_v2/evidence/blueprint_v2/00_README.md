# FE01 论文大纲与 Codex 首稿实施包

版本 v2，修订日期 2026-11-16。依据用户本轮反馈，替代 v1 的题目、结构、素材和写作范围要求。原 v1 文件及科研产物保持不变。

论文题目为 **《基于 DiTing 的早期 PGA 概率预测》**。

## 本轮修订

- 题目与所有论文节标题改为简洁的名词短语，不用冒号或长副标题补充说明。
- 正文采用引言、数据与方法、结果、讨论、结论五节。
- 本篇不讲 ON/OFF 幅值消融，正文、摘要、结论和补充材料均不安排该对照；也不提出由该消融支持的幅值贡献或家族互补机制。
- 真实模型中的物理幅值和有效时长信息仍须在方法中如实说明。删除消融叙事不等于关闭模型幅值输入，也不改变本次固定模型和原结果。
- 正文素材调整为 7 组图、3 张表；原幅值消融图删除，后续图号顺次前移。

## 使用顺序

将本目录或 ZIP 交给 Codex，使用 `08_START_CODEX.txt` 启动。已有 v1 工作应保留并记录后修订，不覆盖原科学报告，不把已有草稿当作可删除缓存。

Codex 按任务书生成真实素材及中文完整首稿，用户回传完整 result commit 或审阅包后，再由 ChatGPT 核对科学内容、调整结构与润色。

## 文件

- `01_PAPER_OUTLINE_CN.md` 包含简化题目、五节正文和图表安排。
- `02_CODEX_TASK.md` 定义素材、首稿、QA 和交付的实施边界。
- `03_ASSET_SPEC.json` 定义 7 组正文图、3 表和 8 组补充资料。
- `04_CLAIM_REGISTER.json` 保留 11 个待源表核实的结论，原 C06 不进入本篇。
- `05_EVIDENCE_INDEX.json` 记录固定结果来源及核验边界，A01 相关保留项仅供完整模型身份追溯。
- `06_REFERENCE_SEEDS.json` 保留原文献检索起点，本轮未重新核验文献。
- `07_REVIEW_CHECKLIST.md` 定义下一轮审稿与本次范围修订的检查项。
- `08_START_CODEX.txt` 为可直接转交的启动指令。
- `09_REVISION_NOTES.md` 记录 v1 到 v2 的变更与图号映射。
- `PACKAGE_MANIFEST.json` 记录本修订包的字节和 SHA256。

本文主线为早期非输入台站的概率预测、空间预测表现及交付边界。本包是规划与实施规范，不是已完成论文或图表，也未修改 GitHub、运行模型或提交超算。
