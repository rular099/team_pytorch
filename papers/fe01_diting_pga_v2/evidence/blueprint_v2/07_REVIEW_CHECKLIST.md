# ChatGPT 第二轮审稿验收清单

本清单只定义后续审阅；不声称现在已审阅不存在的初稿。

## v2 范围检查

- [ ] 题目为《基于 DiTing 的早期 PGA 概率预测》，没有长副标题。
- [ ] 正文为引言、数据与方法、结果、讨论、结论五节；节标题和图表短标题不用冒号。
- [ ] 正文、摘要、结论和补充材料不包含ON/OFF对照、消融图或原C06命题。
- [ ] 模型真实使用的物理幅值/有效时长仍在方法中说明，未虚构仅形状输入模型。
- [ ] 完整模型的真实训练来源保留；未删除原实验或改写checkpoint身份。
- [ ] 7组正文图与3表编号、脚本和交叉引用一致，原F6/F7/F8已前移。

## 第二层 统计与科学解释

- [ ] 十cell权重、field权重、event与pooled权重一致；RMSE计算正确。

- [ ] Shadow识别上下界与CI分开，误报负例人口明确，无面积/每日误报声称。
