当前文件夹包含几个项目，其中主要项目是 team_pytorch，它是一个用来做地震预警的项目，输入若干台站的地震波形，计算地震的震级和震中位置，以及附近任意指定地点的PGA. 它是从原始项目 TEAM 移植而来，把原始的 waveform model 替换成 diting 模型，diting模型是一个地震波大模型，输入单个台站的三通道地震波形，输出的话根据不同子模型有所不同，dpk 子模型是输出震相识别结果，emg输出震级结果，cls输出分类结果，dis输出震中距结果. diting 模型的加载和推理代码在 ditingbench 里，已经将其移植到 team_pytorch 中。移植到时候，我们使用 diting 模型的一部分作为特征提取器，将提取到的特征经过一个简单的神经网络适配到 TEAM 模型，原来diting 模型的任务头则丢弃不用。训练的时候冻结diting特征提取的权重，只优化后续的适配部分以及TEAM 部分。

目前遇到一个问题，diting模型提取到特征对于不同的波形是有区分度的，但是经过简单的神经网络适配之后，区分度大幅度降低，不同波形的 cosine similarity 由0.2 左右上升到 0.8 左右。随着训练的进行，区分度更加降低，最后无论什么波形都输出同样的向量。训练脚本用的 team_pytorch/train_light.py，配置文件为 pga_configs/transformer_japan_overfit.json.
