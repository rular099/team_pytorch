# 二、实验目标和固定设计原则

目标是充分使用冻结 DiTing 的预训练特征，以一个很小的任务网络完成多台站、实时、任意目标位置的 PGA 概率预测。

固定原则：

1. DiTing encoder 冻结，只训练新增的小任务网络。
2. 波形继续使用“每个台站按照当前可见有效波形独立归一化”。
3. 不把 std、RMS、峰值、人工能量、手工衰减函数等作为新增模型特征输入。
4. 保留极小的原尺度波形编码通路，用可学习网络补充绝对幅值信息。
5. 保留事件分支，并使用震源位置和震级辅助监督。
6. 事件表示与观测台站、目标位置在 PGA 读出前发生非线性交互。
7. 使用通用 Linear、MLP、注意力、LayerNorm、残差等模块。
8. 不恢复旧的大型下游网络，不额外增加多层时间 Transformer、台站 Transformer、手工路径修正或场地修正分支。
9. 主方案约 74 万任务参数是设计估算。实现后报告真实参数量，不要为了凑数字改变结构。

## 4.1 当前可见波形与两条特征通路

单个台站输入为三分量、10000 个采样点，整体可表示为 `[B,N,3,10000]`。

先结合当前截止时刻与 storage-valid mask，确定真正可见的有效样本。归一化、幅值编码、DiTing 编码都必须遵守这一边界。

DiTing 通路：

- 在当前可见有效样本上按分量去均值。
- 每台站使用三分量共同的尺度归一化，保留三分量相对幅值关系。
- 不使用未来样本、整条最终记录或其他台站的尺度。
- 使用真实预训练 encoder，严格核验 keys、shapes、checkpoint 身份。
- encoder 不进入 optimizer；父模型调用 `train()` 后 encoder 仍保持 `eval()`。
- 明确保持冻结参数和 buffers 不变，特征提取使用适当的无梯度方式。
- 核对实际原生输出；此前确认的接口为每站 `[1792,200]`。

幅值通路：

- 使用当前可见、保留物理尺度的三分量波形，可以去除当前有效样本均值。
- 不再逐站或逐块消除其幅值尺度；若需数值缩放，只能使用明确记录的固定常数。
- 10000 点按 50 点分块，共 200 块。
- 每块三分量展平为 150 维，共享 `Linear(150,8)+GELU`。
- 输出为 `[B,N,200,8]`，不是整段波形只输出 8 个数。
- 可等价使用 `Conv1d(3,8,kernel_size=50,stride=50)`，注意通道和展平顺序一致。
- 完全无效块排除；部分可见块只读取已到达样本，其他位置补零，并保留有效性信息。
- 不允许先编码完整未来波形，再通过后续 mask 冒充因果输入。

必须核对 DiTing token 的分块起点、步长、padding 和顺序。两个通路同为 200 个 token，不足以单独证明时间对齐。

将 DiTing 每个 token 从 1792 投影到 120 维，再与对应位置的 8 维幅值特征拼接，得到 `[B,N,200,128]`。

## 4.2 台站摘要与坐标融合

使用两个可学习查询，对每站有效时间 token 做学习池化，得到 `[B,N,2,128]`。

池化权重由模型学习，不输入人工波形统计量。保留未做逐样本尺度归一化的 value 通路，避免幅值信息被再次消除。

坐标编码：

`E_c: 3 → 128 → 128`

波形与坐标联合编码：

`m0[i,r] = ψ(concat(u[i,r], E_c(c[i])))`

其中：

`ψ: 256 → 256 → 128`

坐标转换和标准化使用统一、可追踪的定义，保留绝对位置。不要为每个事件单独居中而丢掉绝对地理位置。

## 4.3 事件读取与源辅助监督

使用一个可学习事件 query，从所有有效 `m0` 读取：

- 一层交叉注意力；
- 残差；
- 一个 `128 → 256 → 128` 的 FFN；
- 必要的归一化。

得到事件表示 `e:[B,128]`。

从 `e` 预测：

- 震源位置：三个三维对角高斯混合分量，21 个输出参数；
- 震级：一个高斯分布，2 个输出参数。

两个辅助头可采用 `128 → 32 → output`。核对现有 MDN 参数顺序、正尺度变换、坐标单位和损失实现后复用。

真实震源和震级只用于监督。主方案不把预测源分布的 23 个参数再次拼回 PGA 网络；PGA 直接使用受源监督的完整事件表示 `e`。

事件表示只由当前观测构造，不依赖查询目标集合。

## 4.4 事件条件下的空间编码和 PGA 读出

使用共享 MLP：

`r(c) = φ(concat(e,E_c(c)))`

其中：

`φ: 256 → 256 → 128`

同一 `φ` 同时用于输入台站和目标位置：

- 输入 memory：`m[i,r] = m0[i,r] + r(c[i])`
- 目标 query：`q[j] = r(c_target[j])`

目标读出：

`h[j] = q[j] + CrossAttention(q[j], memory=m)`

输出：

`PGA_MDN[j] = MLP(concat(h[j],e,q[j]))`

PGA MLP 为：

`384 → 256 → 9`

保留三个高斯分量的 PGA 概率输出，与现有 `log10(m/s²)` 评价兼容。

不做目标之间的 self-attention。增加、删除、重排或分块处理其他目标，不应改变同一个目标的预测。无有效输入台站时明确返回不支持状态或沿用经过验证的既有处理，不制造虚假观测。

优先建立清晰的新模型类，避免继承旧大型模型构造器后仍注册大量不用的参数。

# 五、训练配置与有限消融

1. `knet / main_d128 / seed42`
2. `kiknet_borehole / main_d128 / seed42`
3. `kiknet_surface / main_d128 / seed42`

各自从新的任务头初始化开始训练，共用同一预训练 DiTing 身份，不复用旧训练好的 adapter 或 PGA 头。

优先继承 FE02 已验证的训练与评价协议，包括当前可见前缀、normal/random 几何、随机观测时刻、目标角色和 validation 选择规则。主训练预算可沿用 12 epochs、有效 batch 128、现有优化器及学习率方案，并完整输出 resolved config。

不同数据视图的有效样本量可能不同，因此同样 12 epochs 不等于相同更新次数。记录实际更新数、事件抽样数和计算耗时，不宣称它们具有相同计算预算。

损失保留：

- PGA 主损失；
- 现有 distribution-mean Huber 辅助项；
- 定位、震级辅助损失。

起始权重可沿用现有 FE02 设置，但全部配置化，并分别记录原始损失和加权损失。源辅助损失按事件观测实例计算，不能因目标数量或 query chunk 数量增加而重复加权。

准备以下可选消融配置和运行入口，但不要默认全部提交：

- `d64`：任务宽度 64，其余设计保持一致。
- `amp16`、`amp32`：幅值通道 16、32；总宽度仍为 128，相应减少 DiTing 投影维数。
- `pool4`：每台站四个学习摘要。
- `no_source_aux`：保留事件主路径，仅关闭定位、震级辅助损失。
- 主配置的 seed43、seed44。

消融应明确改变了什么；幅值通道变化也改变 DiTing 投影维数，不能称为完全等参数对照。相同形状的公共模块尽量使用可复现、可配对的初始化。

不要默认加入 LoRA、解冻 DiTing、额外物理特征或大规模网格搜索。

## 6.5 Checkpoint 与恢复

至少保留 init、best、last，以及足以回看各 epoch 的小任务头权重。last 保存完整恢复所需的 optimizer、scheduler、AMP 状态、各 rank RNG、训练进度及抽样/日志提交位置。
