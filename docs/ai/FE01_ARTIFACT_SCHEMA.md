# FE01 evidence schema

All production evidence is generated by manual runs, not by this document.
`scripts/fe01/pack_results.py` reports missing artifacts as NOT_PROVIDED.
Local synthetic artifacts carry SMOKE_SCOPE.json and must never be relabeled Japan.

| Artifact | Required identity / contents |
|---|---|
| protocol.lock.json | source/effective config hashes, code hash, shard SHA/size/mtime, split/spatial/weight manifest hashes, sampler, exact validation population hash, common times, AUDIT_PASS |
| data_split_audit.json | every train/val referenced shard and frozen split identity; no test fitting |
| cohort_normalization_audit.json | retained data/event keys by split, explicit exclusions, permitted train labels/counts/mean/std |
| validation_population.csv.gz | dataset/event/time/protocol/query station/role and reconstructable input IDs, locked before scoring |
| pretrained_manifest.json | local files with bytes/SHA, model/source/version/component order, native length/fs, original normalization, overlap/provenance limitations |
| model_interface_audit.json | full/trainable/encoder parameters, trainable names, common structure and initial values fingerprints, outputs/normalization |
| causal_boundary_audit.json | first forbidden point, changed future, input invariant assertion, raw encoder output shapes, station feature/prediction max deltas, upstream limitation |
| query_independence_audit.json | actual configured model batch/order/single query comparison, numeric tolerances/deltas |
| capability_manifest.json / model_time_support.csv | native lengths/fs/endpoints/pre-P/features, each event/time required history, supported/N/A reason; verified lengths do not imply theoretical limits |
| sampler_distribution_audit.json | sampler-only 100000 draws, retained mass/counts/expectations/tolerances; separate from training |
| sample_journals / actual_training_time_histograms.csv | dataset/event/epoch/draw/requested/current times, roles/input/query IDs, valid duration; only checkpoint-committed journal paths enter actual histogram |
| training_curves.csv | committed epoch/update budget, actual/planned/dropped sample counts, lr/loss, selection, wall seconds; failed attempts retained separately |
| predictions.csv.gz / predictions.npz | one dataset/event/time/protocol/query row: split/seed/family, coords and final catalog source, cutoff/history/reference/absolute clock, input IDs/coords, target role/valid flag, storage rule/padding/duration, log10 SI truth, full MDN weights/mu/sigma, point/probability/coverage, numerical status/reason, checkpoint epoch/hash/config hash |
| support_status.csv | every attempted data/event/time/protocol including unsupported_history and empty decisions, never omitted from common support checks |
| provenance.json | checkpoint/config/split/window/stage/population/lock/random-time identities, runtime host/job/device/software/source/dirty-state |
| site_residuals*.csv / station_counts.csv | raw station oracle reference and train-only site baseline, observed/predicted/event-centered residual, n independent events, sparsity flag/bootstrap CI, direction/strength stability |
| paired_event_bootstrap.csv | exact paired keys/population, event clusters, draws/seed, pooled/event-macro and equal-time/protocol endpoint delta/CIs; failure refusal |
| case_selection_manifest.json | validation split hash, metadata-only rule, fixed data/event IDs before prediction |
| grid_predictions.csv.gz | actual independent coordinates, mixture parameters/quantiles/width, time/cutoff interpretation, heuristic coverage; no continuous truth or fabricated station ID |
| replay_* / input_masks/*.npz | every supported actual frame, per-T raw rebuild/cache scope, exact selected station/sample masks, observed metrics/independent-forward consistency, whole-frame encoder/downstream/IO latency P50/P95, cold load/peak memory/absolute result time |
| test_exposure_ledger.json | user-recorded project prior exposure (or unknown), authorization/purpose/recorder, current exact checkpoint/config/protocol identity |
| figure_data / figures | plotted CSV/grid/observed points, scripts/limits/mask/reference provenance, static PNG/PDF and actual-frame GIF; unsupported frames blank |
| SOURCE_IDENTITY.json / artifact_manifest.sha256 | exact source implementation commit, hashed dtbench snapshot/retained license and all bundled files; result inventory marks missing/large external items |

The output mask rule plus exact input IDs and causal cutoff can reconstruct each
evaluation mask from the hashed dataset. Replay additionally exports literal masks.
No raw waveforms or giant checkpoints are committed to Git. Large full exports
remain externally hashed; review bundles retain counts, locked cases and figure data.
